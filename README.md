# Field Shift — website

Free crop-rotation advice for farmers in Punjab, Pakistan, from 25 years of NASA satellite and weather data
(NASA POWER, MODIS, SMAP, GPM IMERG). English and Urdu.

**Live site:** https://hassancodes-max.github.io/fieldshift/

This repository holds only the built static website. The data in `data/` is precomputed by the Field Shift
rotation engine; the 7-day forecast comes live from Open-Meteo.
